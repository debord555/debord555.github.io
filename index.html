Projects

Some of the projects I have completed in the past are:
Code-Switching Detection in English-Assamese Speech
This was my final year project during my B.Tech. at Tezpur University, which I did along with my classmate Ashutosh Yadav. This project attempted to detect the temporal language boundaries in code-switched English-Assamese speech. We evaluated various strategies involving different kinds of features (formants, energy, zero-crossing-rate, MFCCs, Mel spectrograms and Wav2Vec embeddings) with two model architectures: CNN and BiLSTM, achieving upto 0.86 MAE.
Engineering Complaints Portal
This was complaints registration and redressal web portal for Engineering Cell, Tezpur University which I developed in my final year of B.Tech. The server was written in Java using Spring Boot; the frontend is server-rendered using Thymeleaf template engine. This system is currently in use at Tezpur University here.
Bluetooth-Controlled Automated Switch
This appliance is made with the intent to automatically switch on or off electrical appliances at certain set times. This setting can be done using a smart phone which connects with the appliance using Bluetooth LE. The project was made using ESP8266, HM-10 BLE chip, DS3131 RTC and electro-mechanical relays. User-facing Android application was developed using Flutter.
